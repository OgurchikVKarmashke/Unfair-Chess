# Unfair-Chess
Unfair chess for those who find the standard game too easy.

## How to run
1. Download the ZIP file.
2. Double-click
3. Windows Defender may show a warning — click "More info" → "Run anyway"

Unfair mode is **disabled by default** — the AI plays standard chess until you turn it on.

To activate it:

1. Open **Main Menu → Settings**.
<img width="307" height="95" alt="{0BB2ADB1-08AD-46AE-B3BD-538348351384}" src="https://github.com/user-attachments/assets/c4b2b544-3e68-4ef5-be3c-7a8e71b604ea" />

2. Choose your side (White / Black).
<img width="346" height="96" alt="{75AAF676-1CD5-40E8-8074-B93B732D1C47}" src="https://github.com/user-attachments/assets/519aacca-0b06-4781-8bf7-8d7f96eac780" />

3. Toggle **Unfair Mode** for the AI, for yourself, or for both.
<img width="536" height="146" alt="{2AD357C5-73E5-411A-A778-DD963BFCCDA6}" src="https://github.com/user-attachments/assets/a2a1f633-ce89-4594-b143-6d5b10d6fe43" />

4. Click **Details…** to pick which specific rules are active for each side.
<img width="260" height="67" alt="{EC8EF59C-BE67-4955-B31B-7FAD1D29FDB9}" src="https://github.com/user-attachments/assets/1d962c72-5f66-4e92-a85c-943c0368c591" />

5. Hit **Back** and start a new game.
<img width="174" height="62" alt="{3C67E093-F0BF-458E-9262-64A46F10E2C2}" src="https://github.com/user-attachments/assets/180c7628-9ef9-4c31-b7c7-3b5e688a3e02" />

> Rules only work when the master toggle for that side is on. You can pre-configure rules before enabling them.

### Which rule is which

| Rule | What it does |
|---|---|
| Pawn on 3 | Pawns can move 3 squares from their starting position |
| Knight-path | Knight can capture any enemy on its L-path |
| Bishop-jump | Bishop flies over its own pieces |
| Rook-behind | Rook captures the piece right behind a blocker |

Still missing one. It's not in this list.
